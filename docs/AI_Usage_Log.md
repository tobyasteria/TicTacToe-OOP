# AI USAGE LOG — WEEK 1

**Công cụ:** ChatGPT

### Nội dung AI hỗ trợ
- Phân tích yêu cầu đồ án và đề xuất kế hoạch 4 tuần.
- Đề xuất thiết kế các class Board, Move, GameRules và Program.
- Tạo source code C# ban đầu, hỗ trợ đơn giản hóa cấu trúc project.
- Xây dựng 7 bài kiểm thử cơ bản.
- Hỗ trợ sơ đồ UML, README và hướng dẫn Git/GitHub.

### Phần sinh viên thực hiện
- Xác định sử dụng C# theo yêu cầu học phần.
- Xem xét và yêu cầu đơn giản hóa cấu trúc project.
- Chạy chương trình thực tế với .NET SDK 8.0.416.
- Xác nhận kết quả 7/7 bài kiểm thử PASS.
- Quản lý repository và sửa lỗi theo dõi các thư mục bin, obj.

### Đánh giá
AI hỗ trợ tạo bản triển khai ban đầu. Sinh viên tham gia điều chỉnh hướng thiết kế, chạy kiểm chứng và tổ chức source code. Các chức năng mở rộng và kiểm thử bổ sung sẽ được thực hiện trong các tuần tiếp theo.
